# Notebooks — Manufacturing Knowledge Graph Demo

- [`kg_demo_manufacturing.ipynb`](./kg_demo_manufacturing.ipynb): Interactive walkthrough—designed to run on **Cloud Shell** with the **[Data Agent Kit](https://cloud.google.com/products/data-agent-kit?utm_campaign=CDR_0x6cb6c9c7_default_b542779815&utm_medium=external&utm_source=social)** ([docs](https://docs.cloud.google.com/data-agent-kit?utm_campaign=CDR_0x6cb6c9c7_default_b542779815&utm_medium=external&utm_source=social) | [GitHub plugin](https://github.com/GoogleCloudPlatform/data-agent-kit-plugin)) or in **BigQuery Studio (Colab Enterprise)**—showing how to semantically chunk an engineering PDF manual in Cloud Storage with BigQuery's `AI.CHUNK_DOCUMENT`, extract `(Product)-[:CONTAINS_PART]->(Part)-[:MADE_OF]->(Material)` Knowledge Graph triples with `AI.GENERATE` (`gemini-3.8-flash`), and load them into BigQuery for `GRAPH_TABLE` traversal.

See the root [`README.md`](../README.md) for full end-to-end setup and execution instructions.
