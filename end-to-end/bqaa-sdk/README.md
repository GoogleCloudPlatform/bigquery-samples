# BigQuery Agent Analytics SDK Samples

This directory contains a notebook demonstrating how to use the [BQAA SDK](https://github.com/GoogleCloudPlatform/BigQuery-Agent-Analytics-SDK) for agent evaluations. It shows how to use the BQAA SDK's built-in evaluators, LLM as a Judge evaluators, and how to write custom evaluators to understand your agent telemetry.

## Files

- `bqaa-sdk-intro.ipynb`: Intro notebook covering a variety of agent evaluation scenarios with the BQAA SDK.
